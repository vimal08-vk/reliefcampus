🎓 Project Demonstration & Viva Reference Guide

This project implements a complete 3-Tier Layered Architecture:

  • Controller Layer: REST endpoints exposing standard HTTP verbs (POST, GET, PUT, DELETE).
  • Service Layer: Business logic validation (InsufficientInventoryException, CampCapacityExceededException).
  • Repository Layer: Spring Data JPA with derived queries and Hibernate ORM.
  • Database Layer: MySQL / H2 relational tables with proper Foreign Key constraints.
